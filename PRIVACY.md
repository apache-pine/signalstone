# Privacy

Signalstone sends the user's bearer token and requested messaging operations directly to Cisco Webex endpoints. Webex remains the source of truth. Locally, Signalstone stores preferences and a Secret Storage identifier. The token stays in Obsidian Secret Storage. Messages, files, drafts, and directory results are not persisted.

Signalstone has no telemetry, analytics, advertising, tracking pixels, or crash reporting.
